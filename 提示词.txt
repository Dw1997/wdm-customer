功能添加:
个人搜索界面，联系我们->点击调起wx.makePhoneCall 拨打13330143106手机号
实现步骤非常简单，主要分为两步：
页面结构 (WXML)
在页面上放置一个可点击的元素，比如 <button> 或 <view>，并绑定一个点击事件。
html
<view class="container">
  <button type="primary" bindtap="makePhoneCall">
    联系客服：13800138000
  </button>
</view>
逻辑处理 (JS)
在对应的 JS 文件中，编写点击事件的处理函数，调用 wx.makePhoneCall 并传入电话号码。
javascript
Page({
  makePhoneCall() {
    wx.makePhoneCall({
      phoneNumber: '13800138000', // 替换为你要拨打的电话号码
      success: () => {
        console.log('成功唤起拨号界面');
      },
      fail: (err) => {
        console.error('拨号失败', err);
        wx.showToast({
          title: '拨号失败，请检查权限',
          icon: 'none'
        });
      }
    });
  },
});

在微信小程序中，实现“分类商品无极滑动”通常指的是横向滚动浏览分类或商品列表。实现这一效果最核心、最推荐的方式是使用小程序官方提供的 scroll-view 组件。

以下是实现该效果的完整方案与核心要点：

🛠️ 核心实现步骤（横向滑动）

要实现横向滑动，需要 WXML 结构和 WXSS 样式紧密配合：

1. WXML 结构：
使用  组件，并开启 scroll-x 属性。

  
    
      {{item.name}}
    
  

2. WXSS 样式（关键避坑点）：
很多同学发现开启了 scroll-x 却无法滑动，通常是因为忽略了以下两个核心 CSS 属性：
white-space: nowrap;：加在 scroll-view 上，强制内部元素不换行。
display: inline-block;：加在子元素（如 .category-item）上，让它们水平排列。注意：子元素不能使用 float: left，否则会导致滑动失效。

/* 滚动容器 */
.category-scroll {
  width: 100%;
  white-space: nowrap; /* 核心：禁止换行 */
}

/* 内部子元素 */
.category-item {
  display: inline-block; /* 核心：行内块布局 */
  padding: 0 20rpx;
  /* 其他样式... */
}

💡 进阶场景：仿淘宝/京东的双侧联动滑动

如果你指的“无极滑动”是类似淘宝分类页那种左侧一级分类竖向滑动，点击后右侧二级商品自动滑动并吸顶的效果，实现逻辑如下：

整体布局：外层使用 Flex 布局，左侧固定宽度（如 25%），右侧占满剩余宽度（75%）。
左侧分类：使用  实现一级分类的竖向滚动。点击某个分类时，记录下标。
右侧商品：同样使用 。利用 scroll-into-view 属性，当左侧点击时，动态改变右侧 scroll-into-view 绑定的 ID，让右侧自动滚动到对应的分类区域。

⚠️ 为什么不推荐用 Swiper 组件？

虽然 swiper 组件也能实现滑动，但它并不适合做长列表的分类滑动，原因如下：
布局限制：swiper 的 display-multiple-items 属性在动态数据加载时容易出 Bug（例如传入的商品数量少于设置显示的数量时，页面可能会空白）。
性能与体验：swiper 设计初衷是整屏或整块的轮播切换，用来做密集的商品列表滑动显得非常臃肿，且难以精细控制无缝衔接的效果。

🚀 性能优化建议

如果分类或商品列表的数据量非常大（成百上千条），直接渲染会导致页面卡顿。此时建议引入虚拟列表（Virtual List）技术：只渲染屏幕可视区域及附近的一小部分商品节点，随着用户滑动动态替换数据，从而极大降低内存占用，保证滑动的丝滑流畅。
